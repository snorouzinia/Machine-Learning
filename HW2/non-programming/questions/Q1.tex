\section{Clustering Metrics [4pts]}
In the Programming assignment (section 1.3), you should have implemented two clustering evaluation metrics: ARI and Silhouette Coefficient. Keeping those implementations in mind, answer the following questions.

\begin{enumerate}[label=\alph*.]

    \item For each metric, note the range of possible values, then describe what would constitute a ``good'' score and a ``bad'' score. [2pts]

    \item Identify the most notable difference between these two metrics and explain why this distinction is important when evaluating clustering results. [2pts]

\end{enumerate}
